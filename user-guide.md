# User Guide — EV Charging Site Dashboard

## Getting Started

Open the Power BI report and use the **page tabs** at the bottom to navigate between the four report pages.

---

## Page 1: Store Rankings

**Purpose:** Find any store and its EV charging priority status.

### How to Use
1. Use the **slicers** on the left to filter by State, City, Utility, Store Type, Business Unit, or Lease Type.
2. Scroll through the three priority tier tables to find your store.
3. Click the **Map Link** in any row to open that store's location directly in Google Maps.
4. Use the Store Manager column to identify who to contact for that location.

### Tier Tables
| Table | Stores Shown |
|-------|-------------|
| Top Priority | Rank 0 – 50 |
| Mid Priority | Rank 51 – 200 |
| Pipeline | Rank 201+ |

---

## Page 2: Title & Site Plan Status

**Purpose:** Track where each store is in the legal and planning workflow.

### Title Status Section
- Each bar shows **Completed** (dark) vs **Pending** (light) count per stage.
- The **card above each bar** shows average days that stage takes to complete.
- **Click any bar** to drill through to the detailed store table for that stage/status.

### Site Plan Status Section
- Same layout as Title Status, tracking the physical site planning pipeline.
- Real Estate Review = the final milestone — when this is complete, the site is ready.

### Drill-Through Table
After clicking a bar:
- A table appears showing all stores in that specific stage and status.
- Use the **Back button** (top-left arrow) to return to the summary page.

---

## Page 3: Map View

**Purpose:** See the geographic spread of all EV charging sites.

- Each dot on the map represents a store location.
- Colors indicate status (hover for details).
- Use slicers to filter the map by region or status.

---

## Page 4: Completion Summaries (Pie Charts)

**Purpose:** High-level snapshot of overall program health.

| Pie Chart | What It Shows |
|-----------|--------------|
| Title & Memo Status | % of stores with title/memo complete vs. in progress |
| Site Plan Complete | % with site plans finalized |
| Utility App Status | % with utility applications submitted/approved |

Click any pie slice to cross-filter all other visuals on the page.

---

## Tips

- **All filters are cross-page** — slicers on one page may carry over depending on your report configuration.
- **Right-click any visual** for additional options like "See Data" to view underlying records.
- The report reflects **live data** — no need to refresh manually. Data updates as the Teams Excel sheet is updated.
